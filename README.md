# Agricultural Crop Yield Analysis

## 📊 Project Overview

Agricultural Crop Yield Analysis is an individual data analytics project focused on understanding production, crop yield, farming inputs, districts, climate factors, and yield trends using Excel.

The project follows an end-to-end Excel analytics workflow:

**Raw Data → Data Cleaning → PivotTables → Dashboard → Insights**

---

## 🎯 Project Objectives

- Identify the strongest production and yield patterns across agricultural categories.
- Compare states, districts, crops, and seasons to find high-performing areas.
- Evaluate fertilizer and irrigation categories against average yield.
- Examine rainfall and temperature relationships with yield.
- Track average yield changes over time.
- Convert Excel analysis into clear agricultural planning insights.

---

## 🔍 Key Analysis Questions

### Production
- Which crop and season generate the most production?

### Yield
- Which states, crops, and seasons have the highest average yield?

### Inputs
- How do fertilizer and irrigation types differ in yield?

### Districts
- Which districts are high- or low-performing?

### Climate
- Do rainfall and temperature show a strong linear relationship with yield?

---

## 📈 Key Findings

### Production Performance

- **Top Production Crop:** Cotton — 18,521.37 tonnes
- **Top Production Season:** Rabi — 35,951.48 tonnes
- **Second-Highest Crop:** Sugarcane — 17,383.85 tonnes
- **Third-Highest Crop:** Pulses — 17,292.79 tonnes

### Yield Performance

- **Top State Yield:** Karnataka — 4,265.96 Kg/Ha
- **Top Crop Yield:** Pulses — 4,188.02 Kg/Ha
- **Top Season Yield:** Rabi — 4,213.04 Kg/Ha
- **Lowest State Yield:** Punjab — 3,698.61 Kg/Ha

### Inputs & Operations

- **Highest Fertilizer Yield:** Compost — 4,333.3 Kg/Ha
- **Highest Irrigation Yield:** Canal — 4,089.9 Kg/Ha
- **Second Fertilizer:** DAP — 4,132.4 Kg/Ha
- **Second Irrigation:** Borewell — 4,087.1 Kg/Ha

### District & Climate Analysis

- **Highest District Yield:** Bangalore — 5,019.74 Kg/Ha
- **Lowest District Yield:** Hisar — 3,246.39 Kg/Ha
- **Rainfall ↔ Yield Correlation:** -0.006
- **Temperature ↔ Yield Correlation:** -0.020

The climate correlations are close to zero, indicating that rainfall and temperature alone do not show a strong linear relationship with yield in this analysis.

### Yield Trend

- **Peak Month:** 2014-07 — 6,975.8 Kg/Ha
- **Lowest Month:** 2021-10 — 1,026.7 Kg/Ha
- **Observed Period:** 2010–2022

## 💡 Overall Insights

- Cotton records the highest observed production.
- Rabi records the highest observed season production.
- Karnataka has the highest average state yield.
- Bangalore has the highest displayed district yield.
- Compost and Canal show the highest average-yield values among the listed input categories.
- Rainfall and temperature correlations are close to zero, so climate should be interpreted together with crop, season, soil, and location context.
